# Sessy plugin for Claude Code

Connects Claude Code to [Sessy](https://sessy.do), an email observability tool for AWS SES. Claude can look up deliveries, bounces, complaints, opens, and clicks. It cannot send email or change SES settings.

When you install the plugin, Claude Code asks for a Sessy API key. Create one at https://app.sessy.do/api_keys.

Setup details and the list of tools: https://sessy.do/docs/mcp
